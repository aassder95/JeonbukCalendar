    운영 원칙

    • K리그, 코리아컵, 슈퍼컵, ACLE 일정을 관리합니다.
    • 같은 경기의 UID를 유지해 중복 생성을 막습니다.
    • 관리 표식이 있는 일정만 수정하거나 삭제합니다.
    • 공식 발표 전 정보는 추정하지 않습니다.

    Google 사용자 데이터 사용

    Google Calendar 권한은 사용자가 직접 실행한 일정 동기화에만 사용됩니다. 광고, 분석, 데이터 판매 목적으로 Google 사용자 데이터를 사용하지 않습니다.
