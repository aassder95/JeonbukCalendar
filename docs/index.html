JeonbukCalendar

전북현대 경기 일정을 Google Calendar와 동기화하는 개인용 오픈소스 도구입니다.

주요 기능

  • 공개된 전북현대 경기 일정 파일을 불러옵니다.
  • 사용자의 Google Calendar에서 전북현대 일정을 추가하거나 최신 내용으로 수정합니다.
  • 관리 대상 일정에서 더 이상 제공되지 않는 항목을 정리합니다.

Google 사용자 데이터 사용

Google Calendar 권한은 사용자가 직접 실행한 일정 동기화에만 사용됩니다. 이 도구는 광고, 분석, 데이터 판매 목적으로 Google 사용자 데이터를 사용하지 않습니다.
